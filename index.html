Guide

Se connecter

Appuie sur le gros bouton de l’accueil. La première fois, Android demande l’autorisation VPN : accepte-la.

Ajouter une configuration

Dans Profil, appuie sur le bouton + et remplis le formulaire, ou importe un fichier ou un lien. Touche un profil pour l’activer : il apparaît en bas de l’accueil.

Modifier une configuration

Le crayon à côté d’un profil ouvre le formulaire de modification. Un profil verrouillé n’a pas de crayon : ses coordonnées restent cachées et on ne peut pas le modifier.

Tester les hôtes

Menu à trois points, puis « Tester les hôtes » : écris tes hôtes, un par ligne, puis appuie sur « Tester les hôtes ». Chaque hôte indique s’il fonctionne ou non. Le bouton Arrêter coupe le test.

Voir les logs

Sur l’accueil, touche « Logs » ou glisse vers la droite. Tu y vois les connexions, les recherches et les imports. « Copier » envoie le texte, « Effacer » vide la liste.

Rechercher l’IP du téléphone

Menu à trois points : colle tes bons IP dans « Liste des IP », puis lance « Chercher l’IP du téléphone ». Quand l’IP du téléphone est dans ta liste, la recherche s’arrête et tu peux te connecter.

Exporter une configuration

Dans Profil, appuie sur Exporter à côté du profil, coche les verrouillages voulus, puis partage en fichier, QR, lien ou cloud. Un fichier verrouillé est chiffré : personne ne voit l’adresse, l’UUID, l’hôte ni le chemin. La personne ouvre le fichier, choisit l’application et se connecte.

Verrous et limites

Tu peux lier la config à un appareil, bloquer le WiFi ou les appareils rootés, fixer une expiration et limiter les données.

Sécurité

Les serveurs gratuits sont partagés. Évite d’y passer la banque ou des mots de passe importants.
